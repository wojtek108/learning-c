Function Pointers & Callbacks — Quick Reference

The one-page companion to Lesson 9 (book Chapter 28).

The One Idea. Functions are code living in the text segment of memory; a function pointer stores the address of that code. Calling through it is an indirect jump — the same indirection idea as data pointers, aimed at code instead.

Declarations — the parens matter

DeclarationMeansRead (right → left)
int (*fp)(int, int); A pointer to a function taking two ints, returning int. "fp is a pointer to a function(int,int) returning int"
int *fp(int, int); A function named fp returning int * — NOT a pointer. "fp is a function(int,int) returning pointer-to-int"
int (*ops[3])(int, int); An array of 3 function pointers (dispatch table). "ops is an array of 3 pointers to function(int,int) returning int"
typedef int (*binop)(int, int); Name the type binop so declarations read simply: binop f; —

Use — assign, call, pass

int (*fp)(int, int);
fp = add;              // assign: bare name decays, same as &add

int r = fp(2, 3);       // call through pointer (idiomatic)
int s = (*fp)(2, 3);   // call, explicit deref — identical

void operate(int x, int y, int (*op)(int, int));
operate(4, 6, mul);    // pass function as argument (callback)

The callback pattern (inversion of control)

void for_each(int *arr, int n, void (*cb)(int)) {
    for (int i = 0; i < n; i++)
        cb(arr[i]);              // callee decides WHEN; your cb decides WHAT
}

Generic code is written once; behavior is injected per call. This is how qsort, signal, event loops, and GUI handlers work.

qsort() — the standard-library callback

int cmp(const void *a, const void *b) {
    return *(int *)a - *(int *)b;   // ascending; swap a/b for descending
}
qsort(arr, n, sizeof(arr[0]), cmp);

Comparator contract: return negative if a sorts before b, zero if equal, positive if after. Cast the const void * back to your type first.

Dispatch tables — replace if/switch with an index

typedef int (*binop)(int, int);
binop table[] = {NULL, add, sub, mul};   // index 0 = no-op

int result = table[choice](a, b);       // guard choice before indexing!

Pitfalls

MistakeConsequence
Forgetting the parens: int *fp(int, int) Declares a function returning int*, not a pointer. Compiler error when you assign fp = add;.
Calling a NULL / unassigned function pointer CRASH Indirect jump to address 0 — undefined behavior. Always initialize.
Signature mismatch (wrong arg types/count) UB — the callee reads garbage off the stack. Compiler usually warns; use -Wall -Wextra.
Indexing a dispatch table out of range Calling whatever garbage address sits in the table. Guard the index first.

When to reach for it

  • Callbacks — generic loops, event handlers, timers.
  • Dispatch tables — menus, command interpreters, calculators, state machines.
  • Anything the stdlib asks you for behavior — qsort, bsearch, atexit, signal.
